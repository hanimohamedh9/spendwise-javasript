
What SpendWise Does

SpendWise is a simple budgeting application that helps users manage their budget and expenses. The application collects the user's budget and expenses and calculates the remaining balance.

JavaScript Concepts Implemented

The project demonstrates the following JavaScript concepts:

- Variables
- Data types
- User input
- Number conversion
- Calculations
- Functions
- Console output

How Variables Are Used

Variables are used to store important budgeting information.

- "totalBudget" stores the user's total budget.
- "totalExpenses" stores the user's total expenses.
- "remainingBalance" stores the amount of money left after expenses.

How User Input Is Collected
The application uses the JavaScript "prompt()" function to collect the user's budget and total expenses.

The input is converted into numbers using "Number()" so that the values can be used in calculations.

How Calculations Are Performed

SpendWise calculates the remaining balance by subtracting total expenses from the total budget.

The calculation is:

Remaining Balance = Total Budget - Total Expenses

For example:

- Budget = 10,000
- Expenses = 3,000
- Remaining Balance = 7,000

How Functions Help Organize the Code

The "calculateRemainingBalance()" function is used to calculate the remaining balance.

Functions help organize the code by putting a specific task into a reusable block. This makes the program easier to understand, maintain, and reuse.

Testing

The application was tested by entering different budget and expense amounts through the prompts. The calculated results are displayed clearly in the browser console.
